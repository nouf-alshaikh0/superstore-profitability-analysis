POWER BI SETUP  (table name after import: superstore_clean)
=========================================================

1) Home > Get data > Text/CSV > superstore_clean.csv > Load.
   Check Postal Code is Text (not Number) so leading zeros are kept.

2) New measures (Modeling > New measure). Paste one at a time:

Total Sales = SUM ( superstore_clean[Sales] )

Total Profit = SUM ( superstore_clean[Profit] )

Profit Margin % = DIVIDE ( [Total Profit], [Total Sales] )

Order Lines = COUNTROWS ( superstore_clean )

Loss-Making Lines = CALCULATE ( COUNTROWS ( superstore_clean ), superstore_clean[Is Loss] = 1 )

Loss Share % = DIVIDE ( [Loss-Making Lines], [Order Lines] )

   Format: Profit Margin % and Loss Share % -> Percentage, 1 decimal.

3) Sort the discount bands in a logical order.
   New column (Modeling > New column):

Band Order =
SWITCH (
    superstore_clean[Discount Band],
    "No discount", 1,
    "Up to 20%", 2,
    "20-30%", 3,
    "30-50%", 4,
    "50-80%", 5
)

   Select the "Discount Band" column > Column tools > Sort by column > Band Order.
